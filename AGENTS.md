## Git commit

- use conventional commmit messages for commit messages. see [conventional commits](https://www.conventionalcommits.org/en/v1.0.0/) for more information.   
- keep commit messages concise and meaningful
- use the imperative mood in commit messages (e.g., "fix bug" instead of "fixed bug" or "fixes bug")
- seperate the subject line from the body with a blank line
- begin with feature, fix, docs, style, refactor, perf, test or chore

## Security guidelines
Never commit secrets (api keys, passwords, etc.) to the repository. Use environment variables or secure vaults to manage sensitive information.
